# 亞特的冒險：燼野之境 v1.0.11

8-bit 即時動作冒險遊戲，支援手機、平板與桌面操作。

## 本次更新

- 移除標題、暫停與死亡畫面的後五關選關測試入口及測試裝備配發程式。
- 保留單人第 16–20 關的新目標：三波戰鬥、獵殺三名隊長、生存 60 秒、督軍與兩名護衛、12 名敵人後的最終魔王。
- 生命值顯示依畫面寬度切換為愛心或「目前 / 最大」心數，避免手機 HUD 重疊。
- 修正結局「再玩一次」與「回到標題畫面」的觸控操作，回到標題時重播標題動畫。
- 沿用關卡自動存檔，於每關完成後保存下一關起始狀態；存檔鍵與格式不變。
- 保留原本第 1–15 關及連線玩法。

## 本地執行

在專案資料夾執行：

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

Mac 使用 http://localhost:8000；同 Wi-Fi 裝置可透過 Mac 的區域網路 IP 測試。

## PWA 與更新

GitHub Pages 提供 HTTPS。Service Worker 快取完整遊戲供離線啟動；更新下載完成後，由玩家選擇立即更新或稍後。每次發版請同步更新 index.html 與 sw.js 的版本資源路徑。

存檔儲存在同一裝置、同一網站來源；清除網站資料可能失去進度，本地與正式網址的存檔不會自動互通。
