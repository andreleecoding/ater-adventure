## SEO 更新

- 搜尋標題與繁體中文摘要、canonical、Open Graph 與 Twitter 分享預覽。
- VideoGame JSON-LD、語意標題與操作說明中的遊戲介紹。
- 新增 sitemap.xml，正式網址為 https://andreleecoding.github.io/ater-adventure/ 。

- 分享預覽沿用 icon-512.png；實際摘要、索引及分享快取由各平台決定。
- 更新 PWA 快取版本；遊戲邏輯及存檔格式不變。

## 本地執行

在專案資料夾執行：

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

Mac 使用 http://localhost:8000；同 Wi-Fi 裝置可透過 Mac 的區域網路 IP 測試。

## PWA 與更新

GitHub Pages 提供 HTTPS。Service Worker 快取完整遊戲供離線啟動；更新下載完成後，由玩家選擇立即更新或稍後。每次發版請同步更新 index.html 與 sw.js 的版本資源路徑。

存檔儲存在同一裝置、同一網站來源；清除網站資料可能失去進度，本地與正式網址的存檔不會自動互通。
